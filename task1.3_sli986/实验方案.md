# MNIST 手写数字生成：GAN 实验方案

## 1. 目标与作业边界

完成 CS5494 Assignment 任务 1.3：实现并训练 GAN，在原始灰度 MNIST 上生成手写数字，展示生成效果、训练过程与运行时间，并讨论训练稳定性和模式崩溃。

**课程明确要求：**

- 使用原始 MNIST，不能使用任务 1.1、1.2 的二值化版本。
- 可以使用全部训练集或子集，报告说明实际使用数量。
- 提交生成图像和训练稳定性分析。
- 报告说明模型模块、训练过程、训练时间及推理时间。
- 评分关注数据与超参数分析、消融实验，以及方法原理的解释。

**本方案的设计选择：**使用无条件卷积 GAN；安排一个基线、一项学习率对比和一项 BatchNorm 消融。下文的网络、轮数和实验规模均为拟定方案，不是课程指定参数，也不代表已经取得的实验结果。

## 2. 实验问题

| 编号 | 问题 | 观察依据 |
|---|---|---|
| Q1 | 基线能否从随机噪声生成可辨认且具有多样性的数字？ | 最终随机样本、训练阶段图、人工可辨认率与类别分布 |
| Q2 | 同时降低 G、D 学习率，会如何影响固定训练预算下的生成质量与稳定性？ | 相同训练阶段的图像、损失与最终样本统计 |
| Q3 | 移除生成器 BatchNorm，会如何影响学习过程和最终效果？ | 与基线进行单因素比较 |

待检验的预期：降低学习率可能减缓学习，也可能缓解波动；移除 BatchNorm 可能影响稳定性。两者均允许出现相反结果，报告以实际证据为准。

## 3. 数据方案

- 数据：MNIST 原始训练集，共 60,000 张灰度图像；正式实验使用全部训练集。
- 尺寸：保留 `1×28×28`。
- 预处理：像素先转为 `[0,1]` 浮点值，再按 `x' = 2x - 1` 缩放至 `[-1,1]`。
- 不做阈值二值化，不使用数据增强。
- 无条件训练不输入类别标签；标签只可用于说明训练数据分布。
- 每轮打乱训练样本，保留最后一个不足批大小的批次。
- 调试阶段可固定抽取 6,000 张训练图像，仅用于跑通训练，不与正式实验混合统计。

MNIST 测试集不参与 GAN 参数训练。本方案主要做生成质量和稳定性分析，不将判别器准确率当作数字生成质量指标。

## 4. 模型结构

### 4.1 生成器 G

输入 `z ~ N(0,I)`，维度为 100；输出为 `1×28×28` 的灰度图像。

| 顺序 | 层 | 输出形状，不含批次维 |
|---|---|---|
| 1 | Linear，100 → 128×7×7；ReLU | 6272 |
| 2 | Reshape | 128×7×7 |
| 3 | ConvTranspose2d，128→64，kernel=4，stride=2，padding=1；BatchNorm2d；ReLU | 64×14×14 |
| 4 | ConvTranspose2d，64→1，kernel=4，stride=2，padding=1；Tanh | 1×28×28 |

消融实验仅移除第 3 层的 BatchNorm2d，保留其他层及其配置。

### 4.2 判别器 D

| 顺序 | 层 | 输出形状，不含批次维 |
|---|---|---|
| 1 | Conv2d，1→64，kernel=4，stride=2，padding=1；LeakyReLU(0.2) | 64×14×14 |
| 2 | Conv2d，64→128，kernel=4，stride=2，padding=1；LeakyReLU(0.2) | 128×7×7 |
| 3 | Flatten；Linear，6272→1 | 1 个 logit |

D 不使用 BatchNorm 或 Dropout，以减少初始实验中的变量。所有可学习层保留 bias，初始化采用框架默认方案，并记录随机种子。

### 4.3 损失与更新

使用 `BCEWithLogitsLoss`；D 输出 logits，不再额外接 Sigmoid。以下公式中 `D(x)` 指经过 Sigmoid 后的真实概率：

\[
L_D=-\mathbb{E}_{x}\log D(x)-\mathbb{E}_{z}\log(1-D(G(z)))
\]

\[
L_G=-\mathbb{E}_{z}\log D(G(z))
\]

每个批次执行一次 D 更新和一次 G 更新：

1. 采样噪声生成假图像，D 的真实标签为 1，假图标签为 0。
2. 更新 D 时对假图像使用 detach，D loss 为真实项均值与假图项均值之和。
3. 更新 G 时重新采样噪声，假图像的目标标签设为 1；冻结 D 参数，但保留经过 D 向 G 传播的梯度。
4. 不引入标签平滑、噪声注入或额外正则项。

## 5. 统一训练配置

| 参数 | 设定 |
|---|---|
| 框架 | PyTorch，记录实际版本 |
| 设备 | 优先使用一张 GPU，所有正式实验使用相同设备 |
| Batch size | 128 |
| 优化器 | G、D 分别使用 Adam |
| 基线学习率 | G=0.0002，D=0.0002 |
| Adam betas | (0.5, 0.999) |
| Weight decay | 0 |
| 正式训练轮数 | 每个实验 20 epochs |
| 更新比例 | D:G = 1:1 |
| 主实验随机种子 | 42 |
| 固定展示噪声 | 单独以种子 2026 生成 64 个向量，各实验共用 |
| 最终评估噪声 | 单独以种子 2027 生成 200 个向量，各实验共用 |
| 权重选择 | 统一使用第 20 个 epoch 的权重作主比较 |

固定展示噪声用于观察同一输入随训练的变化；最终评估噪声用于统一的结果统计，不从中挑选最好看的图片。采样和绘图使用独立随机数流，避免改变后续训练噪声序列。

## 6. 实验矩阵与预算

| 实验 | 目的 | 学习率 G/D | G 的 BatchNorm | 数据量 | Epochs |
|---|---|---|---|---:|---:|
| E0 | 调试训练流程 | 0.0002 / 0.0002 | 有 | 6,000 | 2 |
| E1 | 正式基线 | 0.0002 / 0.0002 | 有 | 60,000 | 20 |
| E2 | 学习率对比 | 0.0001 / 0.0001 | 有 | 60,000 | 20 |
| E3 | BatchNorm 消融 | 0.0002 / 0.0002 | 无 | 60,000 | 20 |

E0 不纳入结果排名。E1–E3 共需 60 个完整数据集训练轮次。正式训练前测量一个完整 epoch 的耗时，以此估计预算；不预先承诺分钟数。

控制条件：数据、预处理、批大小、优化器参数、训练轮数、G/D 更新比例、初始化策略和评估噪声均保持一致。E2 仅改变共同学习率，E3 仅移除 G 的 BatchNorm。

若时间允许，将 E1–E3 均补充种子 43、44，共得到每配置 3 次运行；报告均值、标准差及单次结果。只有一个种子时，将结论限定为该次运行的观察，不做统计显著性声明。

如果基线在 20 epochs 后仍未形成可辨认数字，先保留并分析失败结果，再决定是否将所有比较配置统一延长至 40 epochs。不能只延长某个配置后直接与其他配置的 20 epochs 结果比较。

## 7. 记录与评价

### 7.1 训练动态

每个 epoch 保存以下记录：

- G loss、D loss，按样本数加权汇总各批次均值。
- D 对真实样本的平均概率与对假样本的平均概率，注明使用 D 更新阶段的输出。
- epoch 耗时、累计训练时间。
- 64 个固定噪声输入的生成图片。

保留原始曲线；如展示平滑曲线，同时保留浅色原始曲线。GAN loss 不作为单独的收敛或生成质量判据。

### 7.2 最终生成质量

每个正式实验在评估模式下生成同一组 200 张图像，映射回 `[0,1]` 用于展示。

1. **随机样本网格：**固定展示其中前 64 张，排成 8×8，不人工筛选。
2. **人工可辨认率：**对全部 200 张依次标注为 0–9 或“无法辨认”；可辨认率 = 可辨认张数 / 200。
3. **类别覆盖：**记录人工可辨认样本中出现的数字类别数，范围 0–10。
4. **类别分布：**展示 0–9 及“无法辨认”共 11 类的计数，避免忽略低质量样本。
5. **重复现象：**记录是否存在大量近似重复的笔画或字形，提供对应样例。

由同一人按相同标准标注各实验，尽量隐藏实验名称。模糊、混合或难以明确区分的图像统一记为“无法辨认”。人工统计是小样本描述，不能替代全面的生成分布评价；类别覆盖高也不能排除类别内部的模式崩溃。

本次核心方案不增加 FID、额外分类器训练或复杂评价网络，以控制工作量。

### 7.3 模式崩溃与稳定性

结合阶段图、最终样本和损失回答：

- 不同噪声是否生成高度相似的图像？
- 是否长期集中在少数数字类别？
- 是否出现中期较好、后期退化或多样性骤降？
- D 的真假判断是否长期极端，同时 G 难以改善？

区分“尚未学会生成数字”和“已生成数字但集中重复”。只观察到模糊噪声，不能直接认定模式崩溃。若未发现明显崩溃，表述为“在本次运行及展示样本中未观察到明显模式崩溃”。

### 7.4 时间统计

- **训练时间：**从第一个训练批次开始到最后一个 epoch 结束；包含定期采样和保存，排除数据下载，报告中注明此口径。
- **推理时间：**G 在评估模式、关闭梯度记录下，生成一批 1,000 张图像；排除模型加载、绘图和磁盘保存。
- 推理先预热 10 次，再重复测量 30 次，报告批次耗时均值与标准差，以及均值除以 1,000 得到的摊销每张耗时。
- GPU 计时在起止处同步设备。摊销每张耗时不等于单张请求延迟。
- 所有配置使用相同设备、批大小和计时方法。

- **基线结果：**说明数字形成过程、最终可辨认性、多样性与失败样例。
- **学习率实验：**结论限定在相同 epoch 预算下；较差结果可能来自学习较慢，不能直接等同于长期效果更差。
